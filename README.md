# Paramedic Medication Field Guide (MedRef)

A fast, responsive, and offline-first web application designed as a quick reference tool for paramedic medication protocols. This guide is based on the Saskatchewan College of Paramedics (SCoP) standards.

[Paramedic Field Guide Screenshot](https://imgur.com/a/VwJGuzE)
_**Note:** You should replace the image URL above with a real screenshot of your application._

---

## 🚀 Key Features

* **Instant Search**: Quickly find any medication by name, indication, or dosage.
* **A-Z Navigation**: Jump directly to medications with a convenient alphabetical index.
* **Fully Responsive**: Works seamlessly on mobile phones, tablets, and desktops.
* **Offline Access**: The application is a single HTML file with no external dependencies (after the initial load), making it reliable in the field without an internet connection.
* **Clean & Readable UI**: A dark-themed, minimalist interface reduces eye strain and makes information easy to digest.
* **Detailed Information**: Each medication includes indications, contraindications, detailed dosing for different age groups, and routes of administration.

---

## 🛠️ Technology Stack

This project is built with simplicity in mind and uses:

* **HTML**: For the core structure and content.
* **Tailwind CSS**: For a modern, utility-first styling approach, loaded via a CDN.
* **Vanilla JavaScript**: For all functionality, including search, filtering, and UI interactions.

---

## 📖 How to Use

There are two main ways to use this tool:

1.  **Local Use (Offline)**:
    * Download the `index.html` file from this repository.
    * Open it in any modern web browser (like Chrome, Firefox, or Safari).
    * That's it! It will work without an internet connection.

2.  **Deploying to the Web**:
    * You can host the `index.html` file on any static site hosting service.
    * GitHub Pages is a great free option.
